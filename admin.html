📋 Enrollment Details

RFID Java Attendance Terminal

The RFID attendance terminal runs as a separate Java desktop app on the scanner PC.

Terminal Setup (scanner computer)
  1. Open the rfid-attendance-system folder.
  2. Windows: Double-click run.bat to start the terminal.
  3. Manual: Run mvn javafx:run from the command line.
  4. Tap RFID card to record attendance — data syncs to this website API.

API endpoint used by terminal: https://OnlineSnlc.bond/api/index.php?action=rfid_tap
